## Menjalankan
1. Buat folder platform (sekali saja), di dalam folder ini:
   `flutter create . --project-name modalku --org com.modalku`
   (file `lib/`, `pubspec.yaml`, dan `assets/` milik kita tidak ditimpa)
2. `flutter pub get`
3. `flutter run`
4. Ikon aplikasi (opsional): `dart run flutter_launcher_icons`

Font (Chakra Petch, DM Sans) diunduh google_fonts saat pertama dibuka, jadi butuh internet sekali.
